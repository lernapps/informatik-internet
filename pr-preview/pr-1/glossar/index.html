Glossar

Die Begriffe dieser App, von A bis Z, jeder mit der Seite, die ihn erklärt.

Client

Ein Programm oder Gerät, das eine Anfrage schickt und auf die Antwort wartet, zum Beispiel der Browser auf Bens Handy.

Erklärt auf der Seite Client und Server

DNS

Das Telefonbuch des Internets (englisch Domain Name System). DNS-Server übersetzen Namen wie www.schule.example in IP-Adressen.

Erklärt auf der Seite IP-Adresse und DNS

Domain

Der Name eines Rechners im Internet, zum Beispiel www.schule.example. Das DNS übersetzt ihn in eine IP-Adresse.

Erklärt auf der Seite Aufbau einer URL

Internet

Ein Netz aus sehr vielen Netzen auf der ganzen Welt. Router verbinden die Netze und reichen Päckchen von Netz zu Netz weiter. Ein Netz, das so über weite Strecken reicht, heißt globales Netz.

Erklärt auf der Seite Aufbau des Internets

Internetdienst

Ein Angebot, das das Internet nutzt, zum Beispiel das World Wide Web, E-Mail oder Chat. Jeder Dienst hat eigene Programme und eigene Regeln.

Erklärt auf der Seite Internetdienste und Protokolle

IP-Adresse

Die Nummer eines Geräts im Netz, zum Beispiel 192.0.2.17. Sie besteht aus vier Zahlen von 0 bis 255, getrennt durch Punkte.

Erklärt auf der Seite IP-Adresse und DNS

lokales Netz

Ein Netz an einem Ort, zum Beispiel in der Schule oder in einer Wohnung. Kurz LAN (englisch local area network).

Erklärt auf der Seite Aufbau des Internets

Mailserver

Ein Server, der E-Mails annimmt, weiterschickt und in Postfächern aufbewahrt, bis sie abgeholt werden.

Erklärt auf der Seite Internetdienste und Protokolle

Protokoll

Feste Regeln, nach denen zwei Rechner miteinander reden. Mehr dazu auf der nächsten Seite.

Erklärt auf der Seite Aufbau einer URL

Router

Ein Gerät, das Netze verbindet und Päckchen weiterreicht, bis sie ihr Ziel erreichen. Im Schulnetz verteilt es sie auch an die Geräte.

Erklärt auf der Seite Aufbau des Internets

Server

Ein Programm oder Rechner, der auf Anfragen wartet und Antworten schickt, oft an viele Clients gleichzeitig.

Erklärt auf der Seite Client und Server

URL

Die Adresse einer Seite oder Datei im Web, zum Beispiel https://www.schule.example/klasse-7b/ausflug.html.

Erklärt auf der Seite Aufbau einer URL

Webserver

Ein Server, der Webseiten schickt, zum Beispiel der Rechner der Schule mit der Ausflugsseite.

Erklärt auf der Seite Client und Server

World Wide Web

Der Dienst für Webseiten. Browser holen die Seiten mit HTTP oder HTTPS von Webservern. Kurz WWW oder Web.
