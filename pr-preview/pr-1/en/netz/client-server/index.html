  1. Ben's phone sends off a request: “The trip page, please!”
  2. The routers pass the request on …
  3. … all the way to the school.
  4. The web server gets the request and looks for the page.
  5. The web server sends the page back as its response.
  6. The routers pass the response on …
  7. … back to Ben.
  8. Ben's phone gets the response and shows the page.
client

A program or device that sends a request and waits for the response, for example the browser on Ben's phone.

server

A program or computer that waits for requests and sends responses, often to many clients at once.

web server

A server that sends web pages, for example the school's computer with the trip page.

Exercise

True or false? Tom's laptop cannot be a server because it is too small.

Right answer: The statement is false.

The statement is not true. If other devices ask Tom's laptop and it answers, it is a server. What counts is the role, not the size.

Solution

Right answer: The statement is false.

The statement is not true. If other devices ask Tom's laptop and it answers, it is a server. What counts is the role, not the size.

Like at the school tuck shop: you order (client), the shop hands it out (server). But the comparison has limits: a server is a program on a computer. It often runs day and night and serves many clients at once.

Remember

Client and server are roles: whoever asks is the client. Whoever answers is the server. It does not depend on size. Even a small laptop can be a server.

Example: the online game

Jona's progress

  1. Jona finishes a level. The game app on his laptop (client) sends a request: “Save my progress.”
  2. The game server (server) saves it and responds: “Saved.”
  3. The next day the app asks: “Where was Jona?” The server responds with the level.

The same game server answers thousands of other players at the same time.
