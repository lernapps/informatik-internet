Can you do this already?

For this chapter you need the building block hardware and software: “I can tell hardware from software and explain how they work together in a computer system.”

Check yourself in your head:

  • You can touch hardware: a tablet, a screen, a cable. A router is hardware too.
  • Software is programs, for example the browser you look at web pages with.
  • They need each other: the software tells the hardware what to do.

Not sure? Read the page Hardware and software in the app “How a computer works”.

Exercise

True or false? The browser on Ben's phone is hardware, because it fetches web pages from the network.

Right answer: The statement is false.

The statement is not true. The browser is a program, so it is software. It runs on the phone's hardware and uses it to send and receive data.
