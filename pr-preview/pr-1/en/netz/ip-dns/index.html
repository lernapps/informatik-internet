Try it: look it up first, then send

IP address

The number of a device in a network, for example 192.0.2.17. It is made of four numbers from 0 to 255, separated by dots.

Every device in a network needs an address. But people prefer to remember names like www.schule.example. That is why there is DNS: a phone book that translates names into IP addresses. The purple DNS server looks them up. Press Next step.

✉ The packet says: to 203.0.113.53, from 192.0.2.25: question about www.schule.example

Ben's phone only knows the name www.schule.example. Press “Next step”.

Map 6: Ben's phone (192.0.2.25) is joined through Ben's router to router 1. Router 1 has the DNS server (203.0.113.53) and the school router with the web server (198.51.100.7).

  1. Ben's phone asks the DNS server: what is the IP address of www.schule.example?
  2. The routers pass the question on.
  3. The DNS server looks up the name and finds 198.51.100.7.
  4. It sends the answer back to the sender's address 192.0.2.25.
  5. The routers pass the answer back …
  6. … and Ben's phone now knows the address of the web server.
  7. Now Ben's phone sends the request for the trip page to 198.51.100.7.
  8. The routers read the number and pass it on …
  9. … into the school network.
  10. The request reaches the web server.
DNS

The phone book of the internet (Domain Name System). DNS servers translate names like www.schule.example into IP addresses.

Remember

Routers read only numbers, not names. That is why the device looks up the name with DNS first. Unlike a phone book, this happens by itself, in a fraction of a second.

For the curious

At home the router gives the devices addresses that only work in the home network, and has one for the internet itself. Newer IP addresses (IPv6) are much longer. The maps show one address per device to keep it simple. The addresses and names here are example addresses and example names: “.example” does not exist, on purpose.

Join in without a computer: the envelope game

How to play

  1. Each child gets a card with an IP address, for example 192.0.2.5. Three children are routers.
  2. One child is DNS. They have a list: name → IP address.
  3. Whoever wants to write only knows a name. They ask DNS for the number.
  4. On the envelope go “to” and “from”, both as IP addresses. The routers pass it on.
  5. The answer goes back to the sender's address.

  • The page does not load. right answer
