Try it: the route of an email

internet service

Something offered over the internet, for example the World Wide Web, email or chat. Each service has its own programs and its own rules.

A protocol sets out who says what and when, as on the phone: first “hello”, then the question, then the answer. Each service has its own. With email the letters travel through two mail servers. Press Next step.

Map 7: Selin sends Ben an email

✉ The packet says: Email to ben@schule.example (SMTP)

Selin has written the email. Press “Next step”.

Map 7: Selin's tablet is at router 1, which also has Selin's mail server. Router 1 is joined to router 2, which has Ben's mail server and Ben's phone.

  1. Selin's email app hands in the email, by the rules of SMTP.
  2. It arrives at Selin's mail server.
  3. Selin's mail server sends it on to Ben's mail server, again with SMTP.
  4. Routers pass it on …
  5. … into Ben's mailbox. It waits there, even if Ben's phone is switched off.
  6. Later Ben's email app asks for new mail and fetches it, by the rules of IMAP.
  7. Ben reads the email.
Three services and their protocols
ServiceProtocol
World Wide Web (web pages)HTTP, or HTTPS: the same, but encrypted
emailSMTP to send, IMAP to fetch
chatthe messenger's rules; one open standard is called XMPP
mail server

A server that accepts emails, sends them on and keeps them in mailboxes until they are fetched.

World Wide Web

The service for web pages. Browsers fetch the pages from web servers with HTTP or HTTPS. WWW or the web for short.

Remember

The internet is the network. The web, email and chat are services that use it. Each service talks by its own protocol.

HTTPS fetches web pages encrypted, SMTP sends emails, IMAP fetches them. A file path is not a protocol but the place of a file.

Exercise

Ben opens the trip page. In which order do the browser and the web server talk by HTTP?

Give each entry its place: 1 for the first.

Right answer: 1. The browser sends: GET /klasse-7b/ausflug.html, 2. The web server looks for the file., 3. The web server answers: 200 OK, with the page., 4. The browser shows the page.

By HTTP the browser always asks first, with GET and a path. The server answers with a number like 200 OK and the page.
