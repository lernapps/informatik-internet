Three parts of a URL

URL

The address of a page or file on the web, for example https://www.schule.example/klasse-7b/ausflug.html.

What each part says
PartWhat it says
protocol: httpswhich rules the browser and the server talk by
domain name: www.schule.examplewhich computer the page is on
path: /klasse-7b/ausflug.htmlwhere the file is on that computer
domain name

The name of a computer on the internet, for example www.schule.example. DNS translates it into an IP address.

protocol

Fixed rules that two computers talk to each other by. More about it on the next page.

Remember

The path of a URL says which page or file on the web server is meant, not on your tablet. Its root is just a slash /. The domain name says which computer is meant; the path says which file on it.

Example: reading a URL

https://museum.example/ausstellung/steine/bild-3.jpg

  1. Before :// is the protocol: https.
  2. Up to the next / is the domain name: museum.example. This is the computer the browser asks.
  3. The rest is the path: in the folder ausstellung, inside it in the folder steine, the file bild-3.jpg.
