Can you do this already?

For this chapter you need the building block file paths: “I can give the place of a file as a path and read a path.”

Check yourself in your head with this path on Mia's tablet:

Mia's tablet/School/German/notes.txt

  • On the left is the root: Mia's tablet.
  • Then the folders, separated by a slash /: School, and inside it German.
  • On the right is the file: notes.txt.

Not sure? Read the page File paths in the app “My files”.

Exercise

Which folder is the file with the path Mia's tablet/Photos/Seeberg/lake.jpg in?

  • Seeberg right answer

    Seeberg comes right before the file. That is where lake.jpg is.

  • Photos

    Photos is the folder one level up. Inside it is the folder Seeberg.

  • Mia's tablet

    Mia's tablet is the root, on the far left. The file is further down the tree.

The name right before the file is the folder it is in.
