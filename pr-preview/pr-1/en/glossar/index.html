Glossary

The terms of this app, from A to Z, each with the page that explains it.

client

A program or device that sends a request and waits for the response, for example the browser on Ben's phone.

Explained on the page Client and server

DNS

The phone book of the internet (Domain Name System). DNS servers translate names like www.schule.example into IP addresses.

Explained on the page IP addresses and DNS

domain name

The name of a computer on the internet, for example www.schule.example. DNS translates it into an IP address.

Explained on the page How a URL is built

internet

A network of very many networks all over the world. Routers join the networks and pass packets on from network to network. A network that reaches this far is called a global network.

Explained on the page How the internet is built

internet service

Something offered over the internet, for example the World Wide Web, email or chat. Each service has its own programs and its own rules.

Explained on the page Internet services and protocols

IP address

The number of a device in a network, for example 192.0.2.17. It is made of four numbers from 0 to 255, separated by dots.

Explained on the page IP addresses and DNS

local network

A network in one place, for example at school or in a home. LAN for short (local area network).

Explained on the page How the internet is built

mail server

A server that accepts emails, sends them on and keeps them in mailboxes until they are fetched.

Explained on the page Internet services and protocols

protocol

Fixed rules that two computers talk to each other by. More about it on the next page.

Explained on the page How a URL is built

router

A device that joins networks and passes packets on until they reach their goal. In the school network it also hands them to the devices.

Explained on the page How the internet is built

server

A program or computer that waits for requests and sends responses, often to many clients at once.

Explained on the page Client and server

URL

The address of a page or file on the web, for example https://www.schule.example/klasse-7b/ausflug.html.

Explained on the page How a URL is built

web server

A server that sends web pages, for example the school's computer with the trip page.

Explained on the page Client and server

World Wide Web

The service for web pages. Browsers fetch the pages from web servers with HTTP or HTTPS. WWW or the web for short.

Explained on the page Internet services and protocols
