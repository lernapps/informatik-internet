Ist das Internet ein großes Kabel?

Ben: Ist das Internet eigentlich ein riesiges Kabel um die ganze Welt?

Selin: Oder ein riesiger Computer, auf dem alles liegt?

Frau Berg: Wir bauen es am Projekttag nach. Fangt klein an: mit zwei Geräten.

Auf dieser Seite lernst du, wie das Internet aufgebaut ist. Am Ende legst du selbst einen Weg durch mehrere Netze.

Aufgabe

Mia und Jona sitzen nebeneinander. Was brauchen ihre Geräte mindestens, damit Mia ein Foto zu Jona schicken kann?

  • Eine Verbindung, mit Kabel oder Funk richtige Antwort

    Zwei Geräte, die verbunden sind, können schon Daten tauschen. Das ist das kleinste Netz.

  • Das Internet

    Das Internet brauchst du für Geräte in anderen Netzen, weit weg. Für zwei Geräte nebeneinander reicht eine Verbindung.

  • Einen Drucker

    Ein Drucker bringt Daten auf Papier. Zum Schicken eines Fotos braucht man ihn nicht.

  • Eine Suchmaschine

    Eine Suchmaschine hilft beim Finden von Webseiten. Sie verbindet keine Geräte.

Schon zwei verbundene Geräte bilden ein Netz. Mit Kabel oder Funk (WLAN) können sie Daten tauschen.

Ausprobieren: Die Karte wächst

Im Netz-Simulator ist jedes Gerät ein blaues Kästchen, jeder Router ein grüner Kreis. Beide nennen wir Stationen. Linien sind Kabel oder Funk (WLAN). Die Daten reisen als Päckchen (gelber Umschlag). Nächster Schritt schickt es ein Kabel weiter, die Liste schreibt mit. Von vorn setzt es zurück.

Router

Ein Gerät, das Netze verbindet und Päckchen weiterreicht, bis sie ihr Ziel erreichen. Im Schulnetz verteilt es sie auch an die Geräte.

lokales Netz

Ein Netz an einem Ort, zum Beispiel in der Schule oder in einer Wohnung. Kurz LAN (englisch local area network).

Ben ist zu Hause, in einem anderen Netz. Die Router der Netze sind verbunden, dazwischen stehen weitere Router.

Karte 3: drei Netze

✉ Auf dem Päckchen steht: Foto für Bens Handy

Das Päckchen liegt bei Mias Tablet. Drück auf „Nächster Schritt“.

Karte 3: drei Netze. Links das Netz der Schule mit Jonas Laptop, Mias Tablet und dem Router der Schule. In der Mitte ein Netz dazwischen mit Router 1 und Router 2, beide mit dem Router der Schule und mit Bens Router verbunden. Rechts das Netz bei Ben zu Hause: Bens Router mit Bens Handy.

  1. Mias Tablet schickt das Päckchen zum Router der Schule.
  2. Bens Handy ist nicht im Netz der Schule. Der Router der Schule reicht das Päckchen nach draußen, zu Router 1.
  3. Router 1 reicht es weiter zum Router bei Ben zu Hause.
  4. Bens Router gibt es an Bens Handy. Das Päckchen ist durch drei Netze gereist.
Internet

Ein Netz aus sehr vielen Netzen auf der ganzen Welt. Router verbinden die Netze und reichen Päckchen von Netz zu Netz weiter. Ein Netz, das so über weite Strecken reicht, heißt globales Netz.

Merke

Das Internet ist kein Kabel und kein riesiger Computer, sondern ein Netz aus vielen Netzen. Router reichen die Päckchen weiter. Oft gibt es mehr als einen Weg: Auf Karte 3 käme das Päckchen auch über Router 2 zu Ben.

Zum Mitmachen ohne Computer: die Zettel-Staffel

So spielt ihr es

  1. Bildet drei Gruppen in drei Ecken des Raums. Jede Gruppe ist ein Netz.
  2. Jede Gruppe wählt ein Kind als Router. Nur Router gehen zu anderen Gruppen.
  3. Ein Kind schreibt einen Zettel „Für Lea in Gruppe 3“ und gibt ihn seinem Router.
  4. Die Router reichen ihn weiter, bis er bei Lea ist.
  5. Ein Router setzt sich hin, er ist „kaputt“. Findet ihr einen anderen Weg?
