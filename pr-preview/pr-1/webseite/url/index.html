Ein Link im Klassenchat

Frau Berg: Hier ist die Ausflugsseite: https://www.schule.example/klasse-7b/ausflug.html

Im Kapitel davor hast du gelernt, wie Geräte sich mit Namen und Adressen finden. Auf dieser Seite lernst du, die Teile einer solchen Webadresse zu benennen.

Welcher Teil von https://www.schule.example/klasse-7b/ausflug.html sieht aus wie ein Dateipfad?

  • www.schule.example

    Das ist ein Name mit Punkten, kein Weg durch Ordner.

  • https://

    Das steht ganz vorn und enthält keinen Ordner und keine Datei.

Drei Teile einer URL

URL

Die Adresse einer Seite oder Datei im Web, zum Beispiel https://www.schule.example/klasse-7b/ausflug.html.

Was jeder Teil sagt
TeilWas er sagt
Protokoll: httpsnach welchen Regeln Browser und Server reden
Domain: www.schule.exampleauf welchem Rechner die Seite liegt
Pfad: /klasse-7b/ausflug.htmlwo die Datei auf diesem Rechner liegt
Domain

Der Name eines Rechners im Internet, zum Beispiel www.schule.example. Das DNS übersetzt ihn in eine IP-Adresse.

Protokoll

Feste Regeln, nach denen zwei Rechner miteinander reden. Mehr dazu auf der nächsten Seite.

Merke

Der Pfad einer URL sagt, welche Seite oder Datei auf dem Webserver gemeint ist, nicht auf deinem Tablet. Die Wurzel heißt dort einfach nur ein Schrägstrich /. Die Domain sagt, welcher Rechner gemeint ist; der Pfad sagt, welche Datei darauf.

Beispiel: eine URL lesen

https://museum.example/ausstellung/steine/bild-3.jpg

  1. Vor :// steht das Protokoll: https.
  2. Bis zum nächsten / steht die Domain: museum.example. Diesen Rechner fragt der Browser.
  3. Der Rest ist der Pfad: im Ordner ausstellung, darin im Ordner steine, die Datei bild-3.jpg.
